# LEGAL-2/3 신뢰출처표 (DRAFT — 오너=도메인 전문가 검증 대기)

> 목적: LEGAL-2(한국)/LEGAL-3(미국) **법적 콘텐츠를 1차 법령에 정박**해, 실행자 WO를 기억이 아닌 출처 기반으로 쓴다.
> 상태: **초안(웹리서치, 2026-07-13).** 각 행의 신뢰도 표기 + 하단 "검증 질문"을 오너가 도메인 눈으로 확정한 뒤에야 LEGAL-2/3 WO 착수.
> 원칙: 앱은 **기록 도구이지 법적 판정 도구가 아님**(기존 DisclaimerView 원칙). 콘텐츠는 "이렇게 기록하도록 돕는다"이지 "이게 법적으로 충분하다"가 아님.

## A. 한국 (LEGAL-2) — 산업안전보건법 위험성평가

| 항목 | 1차 근거 | 요구 | 앱 함의 | 신뢰도 |
|---|---|---|---|---|
| 평가 실시 의무 | 산안법 **제36조** | 사업주가 유해·위험요인 파악→위험성 결정→조치 | 평가 생성·기록(이미 있음) | 高 |
| 근로자 참여 | 산안법 **제36조제2항** + 고시 제2023-19호(전단계 참여 보장) | 평가 전 단계에 근로자 참여, 참여·공유 방법을 실시규정에 명시 | 참여 방법/참여자 기록 필드 | 高 |
| 기록 항목 | 시행규칙 **제37조제1항** | ①유해·위험요인 ②위험성 결정의 내용 ③조치의 내용 ④고용노동부장관 고시 사항 | 이 4항목이 기록/PDF에 포함돼야 | 高 |
| 3년 보존 | 시행규칙 **제37조제2항** | 평가 자료 3년 보존 | 데이터 보존(삭제 UX가 침해 않게)+보존 안내 | 高 |
| 결과 공유 | 고시 제2023-19호(파악·**참여·공유** 중심 재정의) | 결과를 근로자에게 공유·게시 | PDF/공유·게시 기능 | 中(공유 "방법" 구체는 고시·실시규정) |
| 평가 종류 | 고시 제2023-19호 | 최초·정기·수시 + **상시평가 신설(월/주/일)** — 상시로 수시·정기 갈음 가능 | 평가종류에 **상시** 추가 검토(현재 최초/정기/수시) | 中 |
| ⚠️ 참여자 신원 기록 | 시행규칙 제37조 **명시 목록에 "이름" 없음** | 참여는 의무이나, 참여자·근로자대표 "이름" 기록은 고시/실무/감사 차원일 수 있음 | **LEGAL-0 개인정보 게이트** 직결 — 이름 필수/선택 결정 | 低(전문가 검증 필수) |

## B. 미국 (LEGAL-3) — Federal OSHA + State Plans

| 항목 | 1차 근거 | 요구 | 앱 함의 | 신뢰도 |
|---|---|---|---|---|
| JHA/JSA | **연방 명칭 의무 없음**. 근거는 **29 CFR 1910.132(d)** | PPE 위험성평가 + **서면 인증**(평가 장소·인증자·일자·"인증"임을 명시) | US 템플릿은 "정기 JHA 의무"가 아니라 **PPE hazard assessment + 인증 필드** | 高 |
| 추락 임계 | 일반산업 **1910.28=4ft** / 건설 **1926.501=6ft** / 조선 5ft | 업종별 상이(같은 현장 동시 적용 가능) | **일반산업 vs 건설 템플릿 분리** | 高 |
| 연차 JHA 의무 | ❌ 연방 의무 **없음** | 한국식 "정기 위험성평가 의무"를 미국에 투영 금지 | 미국 프로파일에서 "의무 주기" 문구 금지 | 高 |
| State Plan | **22개 주 자체 플랜**(민간+공공). CA Cal/OSHA 더 엄격: **IIPP 8 CCR 3203**·Heat Illness(연방 등가 없음) | 연방=전부 아님 | "연방 기준이며 주(州) 요건이 더 엄격할 수 있음" **고지** | 高 |
| 전기 작업 브리핑 | **1926.952** | 매 작업/교대 전 job briefing(위험·절차·에너지원·PPE) | (선택) 전기 프로파일 | 中 |

| 관할 | 근거 | 성격 |

| 미국(전기) | 1926.952 | 매 작업/교대 전 job briefing |

## D. 오너(도메인 전문가) 검증 질문
1. **참여자 이름**: 시행규칙 제37조엔 명시 없음. 실무/감사에서 참여 근로자·근로자대표 **신원**을 실제로 기록하나요? (LEGAL-0 개인정보 게이트: 필수/선택 확정)
2. **상시평가**: 앱 평가종류에 "상시"를 추가할 가치가 있나요? (현재 최초/정기/수시)
3. **결과 공유 "방법"**: 게시·회람·TBM 중 앱이 어디까지 지원해야 현장 실무에 맞나요?
4. **미국 우선순위**: 일반산업 vs 건설 — 어느 템플릿을 먼저? (추락 임계 4ft/6ft 다름)
