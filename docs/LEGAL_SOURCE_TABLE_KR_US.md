### A.1 참여자 기록 — 3단 분리 (오너 교정 #1)
- **참여자 기록 = 🔴법정 의무** (제37조의4: "참여한 근로자 및 근로자대표"를 기록)
- **이름 또는 사번 = ⚪앱의 식별 방법** (구현 선택 — 법이 "이름"을 명시한 게 아님)
- **서명 = ⚪선택적 증빙** (조문 명시 없음)

**오너 결정 #4 — 식별 단위**: 이름 **필수**, 소속·직무·**사번 선택**(협력업체·소규모 현장은 사번 없을 수 있음). 이름을 기본 식별자로.
```
참여자: 이름(필수) · 소속/직무(선택) · 사번(선택)
        근로자/근로자대표 구분 · 참여 방법(순회/면담/설문/기타) · 참여 시각
        확인 방식(관리자 출석기록[기본] / 본인 확인 / 서명[선택])
근로자대표(별도 상태): 참여 요청 여부 · 참여 여부 · 대표자 이름/식별 · 참여 방법
```

### A.2 결과 공유 = 이벤트 기록 (오너 교정 #2)
**PDF 생성 ≠ 공유 증명.** 공유는 별도 이벤트로 기록(스냅샷 보존 — 원본 평가 수정돼도 과거 공유 불변):
```
공유 시각 · 공유 방법(교육·설명회·게시·서면·전자·TBM) · 공유 대상
공유한 내용의 스냅샷 · 공유 담당자
```
공유 범위 = 유해위험요인 + 위험성 결정 결과 + 개선대책 + **개선대책 이행 결과**.

### A.3 상시평가 = 별도 축 (오너 교정 #3 + 결정 #1)
- 최초·정기·수시 = **평가 종류(kind)**. 상시평가 = 월간 평가+주간 공유+매작업일 TBM으로 정기·수시를 **갈음하는 운영 방식**. → `RiskAssessmentKind.continuous` 금지, **`평가 종류` × `운영 방식` 별도 축**.
- **결정 #1: 완전 지원** — 월간 평가 기록 + 주간 검토·공유 기록 + 매 작업일 TBM 연동. **누락 시 "법적 위반/기한초과" 금지 → "예정/기록 없음/완료" 사실만.**

### A.4 서명 (오너 결정 #2)
기본 = 관리자가 출석 기록. 필요 시 참여자 본인 확인/서명. **기본 선택, 사업장 정책으로 필수화 가능.** 서명 = 참여·전달 확인(책임포기 아님).
